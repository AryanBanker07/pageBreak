# Project Rules — PageBreak Detector

## Development Guidelines

1. **Update `docs/Work Updates.md`** after completing any task or making significant changes.
2. **All processing must remain 100% client-side.** No server calls, no APIs, no data leaving the browser.
3. **Swiss-design principles.** No unnecessary decoration, animations, or graphics. Monochrome palette with `#0066FF` accent.
4. **Privacy first.** User files are never uploaded or transmitted.
5. **TypeScript strict mode.** All code must pass TypeScript strict checks.

## File Conventions

- Components → `components/`
- Processing logic → `lib/`
- App routes → `app/`
- Documentation → `docs/`
